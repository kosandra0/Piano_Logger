🔌 SOUND PLUG-IN / EXTERNAL SYNTH (MIDI OUT)

How to hear Keyzone Classic (or any VST piano) while this page keeps logging

A web page cannot open a plug-in window itself. Instead this page sends every note you play (ST50, PC keyboard, on-screen) out to a virtual MIDI cable, and the plug-in listens on the other end of that cable.

  1. Install loopMIDI (free, by Tobias Erichsen) and click “+” to create one port, for example PianoLogger. Leave loopMIDI running.
  2. Open Keyzone Classic in its own window: use its standalone program if you have one, or load the plug-in file in a free plug-in host such as SAVIHost or Cantabile Lite.
  3. In that program’s audio / MIDI settings, choose MIDI input = PianoLogger and pick your sound-card output. Do not give it the ST50 directly, because Windows lets only one program open the ST50 at a time.
  4. Reload this page, press Connect MIDI, then choose PianoLogger in “Send notes to” and press Test note.
  5. No extra software? Choose Microsoft GS Wavetable Synth in “Send notes to” and pick any instrument from the list: piano, organ, strings, synths and more.

❓ How XP works
Source Rules XP

Your XP so far:

XP is always worked out again from your saved key presses, so it can never be counted twice, and a refresh never adds or removes anything. Your past playing counts too. There are no penalties for breaks. Song auto-play and ear-training notes are not logged, so they earn nothing. XP moves the moment you release each key; above the daily amounts, notes and playing time keep earning at half rate.

Your profile (name, emblem, frame, title and achievement dates) is saved in this browser on this device only. It is not a cloud backup. Because XP comes from your log, restoring a log backup on another device brings your level back.

💡 Tips

Notes fall toward the keys. Play each one as it touches the line. Glowing dots on the keys show what comes next. Green = hit, red = missed. In Wait for me the song pauses until you play the right keys, which is great for learning a new piece. Use loop start / end while the song is paused or playing to repeat a hard part, and slow the speed down. Your presses are still saved to your lifetime log as usual. Notes the page plays for you are not saved.

How to run & troubleshoot

Running it

  1. Easiest: open this file in Chrome, Edge, Brave or Opera.
  2. Recommended: serve it from localhost so MIDI permission and your saved data stay tied to one stable address. In the folder containing this file run python -m http.server 8000 (or py -m http.server 8000 on Windows), then open http://localhost:8000/piano-logger.html.
  3. Always open it from the same address. Browsers store data per address, so a different folder or port starts a new, empty log. Use Backup to move data.

Keyboard not detected?

  • Plug the keyboard in before opening the page, use a data-capable USB cable, and prefer a port directly on the PC.
  • On Windows only one program can use a MIDI port at a time. Close DAWs, Synthesia, other tabs/windows that use MIDI.
  • Allow MIDI when the browser asks. If you blocked it: click the icon left of the address bar → Site settings → MIDI → Allow, then reload.
  • If the keyboard has a USB / MIDI mode setting, make sure USB-MIDI output is enabled.
  • The MIDI monitor under “Latest note” shows raw bytes. If it moves when you play but no note appears, tell me what it shows.
  • If velocity is always the same number, your keyboard probably is not velocity-sensitive (or has a fixed-velocity setting).

Computer keyboard piano

Tick Play with PC keyboard above the piano. The letters appear on the piano keys so you can see which key plays what.

  • Bottom row Z X C V B N M , . / = white keys from C3, with S D G H J L ; as the black keys between them.
  • Top row Q W E R T Y U I O P = white keys from C4, with 2 3 5 6 7 9 0 as the black keys.
  • ← / → shift both rows one octave down / up. You can hold several keys at once.

The History tab labels every press as 🎹 MIDI keyboard (ST50), ⌨ PC keyboard or 🖱 On-screen click.

What is saved

Each press is saved when the key is released (so the held duration is exact). Notes still held when you close the tab are saved at that moment. MIDI number 60 is middle C (C4).

Shortcuts

  • Ctrl + K opens quick search: type any action, such as “theme”, “record”, “backup” or “focus”.
  • Esc closes windows, the tour and focus mode. ← / → on a tab switch tabs.
  • Hover a section and use ⠿ to drag it somewhere else, or ▾ to fold it away. ⚙ → Sections lets you hide or reorder them with the keyboard.

Practice

Open a .mid file (or a demo) in the Practice tab. Choose which parts you play, the hand, the speed and the mode. Your best score per song is remembered.

Sounds

Grand piano downloads real piano recordings (about 2 MB) the first time you pick it and needs internet once per visit. The other instruments are generated live and work offline. The MIDI keyboard's sustain pedal now also holds the built-in sound.

Install on a phone

Served from a web address, you can use the browser's Add to Home screen. A full offline “install” needs two extra files next to this page, so it is not built into this single file.
